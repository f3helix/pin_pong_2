# Пінг-Понг — багатокористувацька гра  
(клієнт–сервер на Python)

## Опис проєкту
Це мережевий варіант класичної гри **Пінг-Понг**, написаний на Python.  
Для графіки використовується **pygame**, а для роботи з мережею — **socket**.

Гра підтримує:
- два гравці (кожен запускає свій клієнт)
- рух м’яча та ракеток у реальному часі
- систему рахунку
- відлік перед початком раунду
- екран перемоги
- **звукові ефекти** (удар об стінку, ракетку, пропущений м’яч)
- зображення заднього фону

Сервер відповідає за логіку руху м’яча та обробку зіткнень.  
Клієнт відображає гру, приймає управління та відтворює звуки.

---

## Функціонал

### Основні можливості
- **Реальний таймінг** — сервер передає стан гри ~60 разів на секунду  
- **Колізії** — м’яч відбивається від стін і ракеток  
- **Гол** — якщо м'яч проходить повз ракетку  
- **Перемога при 10 очках**  
- **Рестарт після завершення гри**
